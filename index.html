Vultr API

获取 API Key

1. 注册 Vultr 账户

通过本站注册链接进入 Vultr，填写邮箱和密码，完成人机验证后创建账户。

2. 充值账户余额

Vultr 需要账户有可用余额或付款方式，才能启用 API。选择支付方式和金额后完成充值。

3. 创建 API Key

进入 API Access 页面，点击 Enable API Access，生成当前账户的 Personal Key。

点击 Copy 复制 Key，勾选确认已复制，再点击 Finalize Key Generation。复制后回到本页粘贴。
